# Simulating LLM Prompt Injection Threat

This example demonstrates the concept of prompt injection, a significant security threat to Large Language Models (LLMs). It simulates an LLM's behavior where a malicious user prompt can override or bypass the model's intended system instructions, potentially leading to data leakage or unintended actions. The script highlights the difference between secure interaction and a successful injection attempt.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
